`context/Known Issues.docx` (example table). English only.

**Do not submit this markdown.** Before packaging, copy the table into the staff
Google Sheet clone and export `.xlsx` into the zip root. Agent instructions:
`.cursor/skills/populate-known-issues/SKILL.md`.

README, HLD, MockMovement catch in DroneControl, UserCommon-only-in-Simulator,
